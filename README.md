## 📌 Overview

An integrated educational platform dedicated to Palestinian Industrial Tawjihi students, providing diverse and comprehensive learning resources.

- **Problem solved:** Difficulty for Industrial Tawjihi students to access reliable and organized educational resources
- **Built for:** Industrial secondary students in Palestine (specializations: Computer Maintenance, Car Electricity, Smart Buildings, and more)
- **What makes it different:** Fully Arabic platform (RTL) that gathers summaries, handouts, exams, and video explanations in one place

## 🚧 Challenges & Solutions

### Challenge 1: RTL (Right-to-Left) Layout
**Problem:** Building a fully RTL website requires careful CSS management  
**Solution:** Used `dir="rtl"` in HTML and adjusted all margins/paddings accordingly  
**Result:** Seamless Arabic interface that feels natural to users

### Challenge 2: Organizing大量 Resources
**Problem:** 20+ subjects and specializations with Google Drive links needed clear organization  
**Solution:** Categorized content into three main sections with grid layouts  
**Result:** Users can find what they need in seconds

### Challenge 3: Mobile Navigation
**Problem:** Navigation links took too much space on mobile screens  
**Solution:** Implemented a hamburger menu with JavaScript toggle  
**Result:** Clean mobile interface with accessible navigation

---

## 📈 What I Learned

- **RTL design requires different thinking** — Everything from margins to icon placement changes
- **Educational platforms need clear organization** — Categories make or break user experience
- **External links are powerful** — Google Drive and YouTube provide unlimited content without hosting costs
- **Accessibility matters** — ARIA labels and semantic HTML improve usability
- **Arabic typography** — Tajawal font is excellent for modern Arabic web design
